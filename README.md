# AI Emotion Detector 🎭

An AI-powered web application that detects emotions in text 
using IBM Watson NLP API, built with Python and Flask.

## 🚀 Features
- Detects 5 emotions: anger, disgust, fear, joy, sadness
- Identifies dominant emotion automatically
- Clean web interface
- Error handling for blank inputs
- Deployed on IBM Cloud

## 🛠️ Tech Stack
- Python
- Flask
- IBM Watson NLP API
- REST APIs
- Unit Testing (unittest)
- PyLint (10/10 score)

## 📁 Project Structure
- EmotionDetection/ — Python package
- server.py — Flask web server
- test_emotion_detection.py — Unit tests
- templates/ — HTML files
- static/ — JavaScript files
